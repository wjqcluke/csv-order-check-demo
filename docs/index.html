让差异有据可查

订单号保留原样

不转数字、不去空格。前导零与长订单号按原始文本匹配，避免误合并。

金额精确到分

合法金额按整数分值比较。支持零和负数；格式错误明确列出，不猜测、不四舍五入。

差异一次导出

完整工具可导出全部差异CSV，保留原始行号及重复记录，方便人工复核。

适用范围

  • 带表头的UTF-8、逗号分隔CSV。
  • 每份最多10MiB、50,000条记录。
  • 两侧自行指定订单号与金额列。
  • 两表币种、金额单位与业务口径一致。

使用前请确认

  • 不直接读取Excel文件或GBK编码。
  • 不自动合单、换汇、分账或抵销退款。
  • 发现差异不代表哪一侧正确，仍需人工复核。
  • Excel导入结果时将订单号列设为文本。
